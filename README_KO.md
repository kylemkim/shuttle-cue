# 🏸 Shuttle Cue — 배드민턴 솔로 훈련 PWA (v1.3)

갤럭시 Z Flip 5 등 안드로이드 휴대폰의 Chrome 브라우저에서 설치해 사용하는 **랜덤 신호 배드민턴 훈련 앱**입니다. 별도 서버 프로그램이나 Python 실행이 필요 없습니다.

## V1.3 변경 사항 및 기본값

- **디자인:** 기존 초록·민트 중심 UI를 밝은 파스텔 하늘색과 푸른 강조색으로 변경했습니다. 앱 아이콘, 브라우저 테마 및 훈련 애니메이션도 같은 계열로 맞췄습니다.
- **언어 변경:** English (UK) 제거 → 日本語 (ja-JP) 추가. B는 짧은 일본어 방향, C는 일본어 숫자를 읽습니다.

- **언어 선택:** `English (US)` → `한국어` → `日本語`. 기본값 **en-US**. 설정은 B와 C 모두에서 공유됩니다. A는 언어와 무관하게 기존 비프음을 사용합니다.
- **음성 속도:** **0.8~1.6배**, 0.1배 단위, 기본값 **1.2배**. 언어와 별개로 저장됩니다.
- **이전 버전 설정 이어받기:** V1/V1.1/V1.2의 저장값이 같은 브라우저·같은 사이트 주소에 있다면 훈련 모드, 시간, 간격, 복귀 시간, 방향 및 번호 선택을 V1.3으로 가져옵니다. V1의 음성 속도와 언어는 **en-US / 1.2배**로 시작합니다. V1.1/V1.2의 언어·속도 설정은 유지하며, 제거한 `en-GB`만 `en-US`로 자동 전환합니다. 기존 저장 자료는 삭제하지 않습니다.
- 언어 또는 음성 속도를 바꾸면 즉시 저장됩니다. 훈련 도중에는 설정 변경이 잠깁니다. `🔊 음성 테스트`에서 선택한 언어를 확인하세요.
- **아직 배포 전이라면 이전 버전은 올리지 말고 V1.3 파일만 새 저장소에 업로드하세요.** 기존 배포가 있는 경우에만 동일 저장소에 파일을 덮어쓰면 됩니다. 캐시 이름은 `shuttle-cue-v1.3.0`이며, 앱 하단에 `v1.3 · PWA`가 표시됩니다.


### V1.3: 0.1초 단위 고속 신호 지원 (배포 전 개선)

- A/B/C 각 모드의 **랜덤 신호 최소·최대 간격**을 **0.1~5.0초** 사이에서 각각 **0.1초 단위**로 설정합니다. 기본값 1~3초 유지.
- B의 **중앙 복귀 시간**도 **0.0~8.0초 사이 0.1초 단위**로 조절할 수 있습니다. 기본값 2초 유지.
- 슬라이더는 손가락으로 작은 값을 정확히 맞추기 어려울 수 있으므로 각각 **`− 0.1` / `+ 0.1` 버튼**을 추가했습니다. 슬라이더와 버튼은 동일한 설정 값을 갱신합니다.
- 랜덤 시간은 최소와 최대 사이의 연속적인 값으로 생성합니다. 예컨대 0.3~0.7초면 0.438초처럼 발생할 수 있습니다. **0.1초는 설정 해상도이지 실제 소리의 정확도나 무작위 값의 격자 단위를 뜻하지 않습니다.**
- 신호 시간은 약 25ms 주기로 확인하되 브라우저/스마트폰 부하가 있으면 지연될 수 있습니다. 밀리초 정밀도를 보장하지는 않습니다.
- **C.Grip의 영어·한국어·일본어 숫자 TTS는 너무 짧은 간격에서 다음 발화가 이전 발화를 취소할 수 있습니다.** 1.2배 음성 속도에서 약 0.6~1.0초부터 시험해 보고, 발음이 온전히 들리면 간격을 줄이세요.
- A.Reaction은 빠른 설정에서 비프음 재생 길이를 최대 간격보다 짧도록 자동으로 줄여 소리 중첩을 완화합니다.
- 같은 GitHub Pages 주소에 올렸다면 V1.2의 개인 훈련 설정을 V1.3으로 가져옵니다. 설정이 5초를 넘는 경우 새 상한 5.0초로 조정합니다.

## 1. 완성된 기능

| 모드 | 음성 / 소리 | 기본 간격 | 핵심 기능 |
| --- | --- | --- | --- |
| **A. Reaction** | 0.16초 비프음 | 랜덤 1~3초 | 스플릿 스텝 반응 훈련 |
| **B. Footwork** | 8방향 **영어/한국어/일본어 음성** | 복귀 2초 + 랜덤 1~3초 = **3~5초** | 방향 선택·복귀 시간 변경 |
| **C. Grip** | 1~10 **영어/한국어/일본어 숫자 음성** | 랜덤 1~3초 | 훈련할 숫자 선택·그립 전환 |

기본 훈련 시간은 1분이며 **30초 / 1분 / 2분 / 3분** 중 선택할 수 있습니다. 모든 모드는 최초에 **3, 2, 1** 카운트다운을 거친 뒤 신호를 시작합니다.

### B: 8방향 음성 지시

| 구역 | 화면 표시 | en-US (기본) | ko-KR | ja-JP |
| --- | --- | --- | --- | --- |
| 앞 왼쪽 | 왼쪽 앞 | **Front Left** | 왼쪽 앞 | ひだりまえ (左前) |
| 앞 중앙 | 정면 | **Front** | 앞 | まえ (前) |
| 앞 오른쪽 | 오른쪽 앞 | **Front Right** | 오른쪽 앞 | みぎまえ (右前) |
| 오른쪽 사이드 | 오른쪽 사이드 | **Right** | 오른쪽 | みぎ (右) |
| 왼쪽 사이드 | 왼쪽 사이드 | **Left** | 왼쪽 | ひだり (左) |
| 뒤 오른쪽 | 오른쪽 뒤 | **Back Right** | 오른쪽 뒤 | みぎうしろ (右後ろ) |
| 뒤 중앙 | 뒤 | **Back** | 뒤 | うしろ (後ろ) |
| 뒤 왼쪽 | 왼쪽 뒤 | **Back Left** | 왼쪽 뒤 | ひだりうしろ (左後ろ) |

일본어는 TTS 오독을 줄이기 위해 `ひらがな`로 발화합니다. 화면의 방향 이름은 기존 한국어를 유지합니다. 숫자는 사용하지 않습니다. 선택한 방향 중에서 무작위로 지시하며, **같은 방향이 연속해서 나올 수도 있습니다.**

**B 모드의 정확한 시간 계산:**

```javascript
// 신호를 출력한 순간을 now라고 할 때
state.nextAt = now + (settings.recovery + randomSeconds('footwork')) * 1000;
```

- `settings.recovery`: 중앙으로 돌아올 시간(기본 **2초**, 설정 **0~8초**, 0.1초 단위)
- `randomSeconds('footwork')`: **최소 1초~최대 3초 사이** 임의 대기(각각 변경 가능)
- 따라서 기본값은 **신호 시작 시점부터 다음 신호까지 3~5초**입니다. 일본어 발화도 같은 시간 계산을 적용합니다.
- **첫 번째 신호**는 3초 카운트다운 뒤 복귀 시간 없이 랜덤 **1~3초** 후 나옵니다.
- 앱은 **다음 신호까지 남은 초**를 화면에 보여주지 않습니다. 이 숫자를 알면 예측 가능해져 반응 훈련 효과가 줄어들기 때문입니다.

## 2. 갤럭시 Z Flip 5에 설치하는 방법 (GitHub Pages)

PWA 설치에는 보안 연결인 **HTTPS**가 필요합니다. 사용자의 휴대폰에 앱을 직접 밀어 넣거나 공개 URL을 자동으로 생성하지는 않습니다. 아래의 무료 정적 웹 호스팅 방법을 이용하면 됩니다.

1. 다운로드한 `Shuttle_Cue_PWA_v1.3.zip` 압축을 해제합니다.
2. [github.com](https://github.com/)에 로그인하여 **New repository**를 만듭니다. 예: `shuttle-cue` (무료 계정에서는 **Public** 저장소가 가장 간단합니다).
3. 해당 저장소에서 **Add file → Upload files**를 선택하고, 압축 해제한 폴더 **안에 있는 파일과 `icons` 폴더**를 업로드합니다. **`index.html`이 저장소 최상위에 있어야 합니다.** ZIP 파일 자체를 업로드하면 실행되지 않습니다.
4. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch → main → / (root) → Save**를 선택합니다.
5. Pages에 표시된 공개 주소를 갤럭시의 **Chrome**으로 엽니다. 보통 주소는 `https://사용자이름.github.io/shuttle-cue/` 형식입니다.
6. Chrome 오른쪽 상단 **⋮ 메뉴 → 앱 설치** 또는 **홈 화면에 추가**를 누릅니다. 정확한 메뉴 명칭은 Chrome 버전에 따라 다를 수 있습니다.
7. 설치된 **Shuttle Cue** 아이콘을 실행한 뒤, **소리 테스트**부터 진행합니다.

> GitHub Pages에 올린 소스는 공개될 수 있습니다. 이 프로젝트에는 개인 정보·계정 키·서버 연결이 없고 개인 훈련 설정은 휴대폰 브라우저에만 저장됩니다.

### 컴퓨터에서 먼저 테스트

압축을 푼 프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
python -m http.server 8000
```

PC 브라우저에서 `http://localhost:8000/`을 엽니다. `localhost`는 보안 컨텍스트로 취급돼 PWA 등록도 테스트할 수 있지만, **휴대폰에서 실제 설치하려면 위와 같이 HTTPS 주소를 쓰는 것이 좋습니다.**

## 3. 훈련 전 꼭 확인할 점

- **음량**: 휴대폰의 **미디어 음량**을 켜고 A의 `비프음 테스트`, B/C의 `음성 테스트`를 누릅니다.
- **언어별 TTS**: B/C는 Web Speech API를 사용합니다. English (US) / 한국어 / 日本語 중 선택하세요. 해당 언어의 음성이 기기에 없다면 브라우저가 대체 목소리를 쓰거나 음성을 출력하지 못할 수 있습니다. Chrome과 갤럭시의 TTS 음성 데이터를 확인하고 **음성 테스트**로 실제 발음 및 지연을 확인하세요.
- **오프라인**: 앱 화면과 설정, 비프음 타이머는 최초 로딩 후 오프라인에서도 동작하도록 캐시합니다. 다만 B/C의 **영어·한국어·일본어 음성은 기기의 TTS 엔진 및 설치된 음성 데이터에 따라 오프라인 사용이 달라집니다.**
- **화면**: 화면을 켠 상태에서 훈련하도록 설계했습니다. Wake Lock 지원 기기에서는 화면 켜짐을 요청합니다. 브라우저 전환, 잠금, 백그라운드 진입 시 타이머 정확도가 깨질 수 있어 **자동 일시정지**합니다. 이어하기로 다시 시작할 수 있습니다.
- **정확도**: JavaScript 타이머는 일반적인 체력 훈련용입니다. 오디오-비디오 동기화 실험처럼 수 밀리초 단위 정확도는 보장하지 않습니다.
- **주변 안전**: 휴대폰은 코트 밖 안전한 곳에 두고, 장애물이 없는 공간에서 훈련합니다. 무리한 방향 전환·착지는 피합니다.

### Python 엔지니어를 위한 JavaScript 핵심 대응표

| JavaScript | Python 비슷한 표현 | 의미 |
| --- | --- | --- |
| `const x = 3` | `x = 3` | 재할당할 수 없는 변수 바인딩 |
| `let count = 0` | `count = 0` | 재할당 가능한 변수 |
| `() => {...}` | `lambda: ...`와 유사 | 함수 표현식(여러 문장 가능) |
| `Math.random()` | `random.random()` | 0 이상 1 미만 균등 난수 |
| `setInterval(callback, 25)` | `while` 루프+시계 확인과 유사 | 약 25ms마다 상태 점검 요청 |
| `performance.now()` | `time.perf_counter()` | 단조 증가하는 고정밀 시간 기준 |
| `localStorage.setItem(...)` | 간단한 로컬 설정 파일 저장과 유사 | 브라우저에 설정 보존 |
| `SpeechSynthesisUtterance('Seven')` | OS TTS API 호출 | 숫자 음성 출력 |

**반복 훈련 구조**는 `app.js`의 `begin() → deliverCue(now) → pause()/resume() → finish()`입니다. `Math.random()`이 만드는 시간 값을 다음 신호의 데드라인 `state.nextAt`으로 저장하고, `performance.now()`가 그 데드라인을 넘으면 새 신호를 재생합니다. 단순히 `setInterval(1000)`을 호출하는 것보다 중단·재개 시 남은 시간을 다루기 편한 구조입니다.

**커스터마이징**: 기본 설정은 `DEFAULTS()`, 방향 선택 목록은 `DIRECTIONS`, 영어 방향 표현은 `ENGLISH_DIRECTIONS`, 일본어 방향은 `JAPANESE_DIRECTIONS`, 그립 매핑은 `GRIPS`, 영어 숫자 표현은 `ENGLISH_NUMBERS`, 일본어 숫자는 `JAPANESE_NUMBERS`, 언어는 `voiceLanguage`, 목소리 속도는 `voiceRate`, 종료 시간은 `duration`에서 변경할 수 있습니다. 코드를 수정하여 재배포할 때는 `service-worker.js`의 `CACHE` 문자열 버전을 올려 주면 기존 캐시를 확실하게 교체하기 쉽습니다.

## 5. 개인정보·권한

회원가입 없음, 광고 없음, 외부 서버 전송 없음, 카메라·마이크·위치 권한 없음. 선택한 훈련 설정만 브라우저의 `localStorage`에 저장됩니다. TTS 엔진의 네트워크 이용 여부는 OS와 브라우저에 따라 달라질 수 있습니다.
