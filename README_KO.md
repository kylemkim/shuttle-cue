# 🏸 Shuttle Cue PWA V1.5 — Sky Blue Combo Voice Edition

갤럭시 Z Flip 5에서 웹앱처럼 설치하는 개인용 배드민턴 신호 훈련기입니다. HTML/CSS/JavaScript 기반이고, 계정이나 별도 서버·DB가 필요하지 않습니다. 기존 밝은 하늘색 파스텔 UI와 A/B/C/D 훈련 기능을 유지합니다.

> **기존 V1.4가 정상 작동한다면 새 저장소를 만들지 마세요.** `kylemkim/shuttle-cue` 기존 저장소에 V1.5 앱 파일을 덮어씁니다. 앱 주소는 `https://kylemkim.github.io/shuttle-cue/` 그대로입니다.

## 1. V1.5에서 새로 추가한 기능

### D. Combo — 음성 지시 방식 선택

| 선택 | 실제 음성 예시 (English US) | 동작 방식 |
| --- | --- | --- |
| **① 2단계 지시 (기본값)** | `Right` → (설정한 지연) → `Smash` | 방향 음성이 **완전히 끝난 뒤** 0.0~2.0초 기다리고 스트로크를 별도 TTS로 발화 |
| **② 한 번에 지시 (신규)** | `Right, Smash` | 방향과 스트로크를 **하나의 문장/한 번의 TTS 호출**로 발화 |

**주의: V1.4의 ‘방향 → 스트로크 간격 0초’는 동시지시가 아닙니다.** 방향 음성 종료 직후 다음 음성을 읽는 두 개의 별도 TTS 호출입니다. V1.5에서는 `② 한 번에 지시`를 선택해야 한 문장으로 읽습니다. 두 소리를 겹쳐서 재생하는 것은 아닙니다.

- 2단계 지시 모드에서만 지연 슬라이더가 표시됩니다. **기본 지연 0.7초**, 범위 0.0~2.0초, 간격 0.1초입니다.
- 한 번에 지시 모드에서는 지연 설정을 사용하지 않지만, 이전에 선택한 지연값은 유지되므로 2단계로 돌아가면 그대로 사용합니다.
- 두 방식 모두 음성 재생이 끝난 뒤 **D 중앙 복귀 시간 + 추가 랜덤 대기**를 적용합니다.
- 기본 음성 언어: English US (`en-US`), 속도 1.2배. 한국어 및 일본어 지원. 예를 들어 `오른쪽, 스매시` / `みぎ、スマッシュ`를 한 번에 발화합니다.
- 선택 방식과 시간 설정은 로컬 저장소에 자동 저장됩니다.

### D. Combo — 좌우 사이드 스매시 추가

| 풋워크 코너 | V1.4 | V1.5 기본 선택 |
| --- | --- | --- |
| **오른쪽 사이드** | 포핸드 드라이브 | **포핸드 드라이브 + 스매시** |
| **왼쪽 사이드** | 백핸드 드라이브 | **백핸드 드라이브 + 스매시** |

사이드의 스매시는 별도 숫자나 그립을 강제하지 않는 일반적인 **`Smash`** 신호입니다. 본인이 사용하는 타점과 기술에 맞춰 훈련하세요. 원치 않는 방향/스트로크는 코너별 체크박스에서 제외할 수 있습니다.

기본 조합은 **23개 → 25개**로 늘어났습니다.

| 방향 | V1.5 기본 선택 스트로크 |
| --- | --- |
| 왼쪽 앞 | 백핸드 언더, 백핸드 푸쉬, 헤어핀 |
| 정면 | 포핸드 언더, 백핸드 언더, 포핸드 푸쉬, 백핸드 푸쉬, 헤어핀 |
| 오른쪽 앞 | 포핸드 언더, 포핸드 푸쉬, 헤어핀 |
| 오른쪽 사이드 | **포핸드 드라이브, 스매시** |
| 왼쪽 사이드 | **백핸드 드라이브, 스매시** |
| 오른쪽 뒤 | 클리어, 스매시, 드롭 |
| 뒤 | 클리어, 스매시, 드롭 |
| 왼쪽 뒤 | 클리어, 스매시, 드롭, 백핸드 클리어 |

## 2. 유지된 훈련 기능

| 모드 | 신호 | 설정 |
| --- | --- | --- |
| A. Reaction | 랜덤 비프음 | 최소·최대 간격 0.1~5.0초, 비프음 크기 |
| B. Footwork | 8방향 음성 | 방향 선택, 중앙 복귀 + 랜덤 대기 |
| C. Grip | 숫자 1~10 음성 | 번호 선택, 최소·최대 간격 0.1~5.0초 |
| D. Combo | 방향 + 스트로크 | **2단계 / 한 번에 지시**, 코너별 스트로크, 지연(2단계 한정), 복귀 + 랜덤 대기 |

- 무작위 간격과 복귀시간 슬라이더는 **0.1초 단위**입니다. ±0.1 버튼도 사용할 수 있습니다.
- 훈련 시간: 30초, 1분, 2분, 3분.
- 시작 전 3초 카운트다운, 일시정지·재개, 종료, 소리 테스트 및 언어·속도 선택 유지.
- 일시정지 중 음성이 중단되고, 재개 시 해당 단계부터 다시 읽습니다. 중복 카운트되지 않습니다.
- D의 방향+스트로크 한 조합을 **1회**로 계산합니다.
- 직전과 동일한 조합 반복 방지 옵션 유지. 선택 가능한 조합이 1개일 때는 반복됩니다.
- B/C의 매우 짧은 음성 간격은 앞 음성을 중간에 끊을 수 있습니다. D는 음성 종료 이후 지연/복귀 시간을 계산하며, TTS 지연이나 폰 성능에 따라 실제 간격은 달라질 수 있습니다.

## 3. 기존 V1.4 설정의 이전

V1.5는 `shuttle-cue-settings-v1.5`라는 새 브라우저 로컬 저장소 키를 사용합니다. 최초 실행 시 V1.4 → V1.3 → V1.2 → V1.1 → V1 순서로 기존 설정을 찾아 복사합니다.

- 기존 훈련 시간, 랜덤 최소·최대 간격, 음성 언어와 속도, D 복귀 시간, D 코너별 선택 등을 유지합니다.
- 음성 지시 방식은 기존 D 동작과 같은 **‘2단계 지시’**로 시작합니다.
- 이전에 사이드 드라이브를 활성화했다면 그 방향에 새 **스매시**를 추가합니다. 기존에 해당 사이드를 모두 비활성화했다면 그 방향을 강제로 켜지 않습니다.
- V1.5에서 스매시를 체크 해제하면 다음 실행 때 다시 추가하지 않습니다.
- 모든 25개 기본 조합으로 돌아가고 싶다면 D 모드의 **‘추천 조합 복원’**을 누르세요. (D의 선택 조합만 초기화)

브라우저 저장 공간을 삭제하거나 시크릿 창으로 접속하면 설정이 사라질 수 있습니다. 설치된 PWA와 브라우저의 저장 공간은 환경에 따라 별도로 취급될 수 있습니다.

## 4. 앱 파일 구성

```text
shuttle-cue/
├── index.html             # 화면과 탭, v1.5 표시
├── styles.css             # 하늘색 파스텔 테마 + 음성 방식 선택 버튼
├── app.js                 # 랜덤 신호, D TTS 한 번/2단계, 타이밍, 설정
├── manifest.webmanifest   # 홈 화면 설치 정보
├── service-worker.js      # v1.5.0 오프라인 캐시
├── icons/
│   ├── icon.svg
│   ├── icon-192.png
│   └── icon-512.png
├── README_KO.md
└── DEPLOY_GUIDE_KO.md
```

PWA 파일은 HTTPS 호스팅이 필요합니다. 한 번 불러온 앱의 정적 파일은 서비스 워커에서 캐시하지만, 시스템 TTS 언어 팩이 오프라인 상태에서 작동할지는 갤럭시 음성 엔진 환경에 따라 다릅니다.

## 5. 배포 전후 검증 체크리스트

1. GitHub `kylemkim/shuttle-cue` 저장소 `main` 브랜치의 루트에 V1.5 **압축을 해제한 파일**을 업로드/덮어씁니다.
2. GitHub Actions에서 Pages 배포 성공을 확인합니다.
3. `https://kylemkim.github.io/shuttle-cue/`을 열어 푸터의 `v1.5 · PWA`를 확인합니다.
4. `D. Combo` → **‘② 한 번에 지시’** → 음성 테스트를 누릅니다. `Front Left, Backhand Under`처럼 **한 문장**으로 발화해야 합니다.
5. **‘① 2단계 지시’**로 변경하고 지연을 0.0초로 설정합니다. 방향과 스트로크가 **두 번에 나눠 발화**되는지 확인합니다.
6. `오른쪽 사이드`, `왼쪽 사이드`를 펼쳐 각각 **드라이브 + 스매시** 선택 항목이 있는지 확인합니다.
7. 실제 갤럭시에서 English US/한국어/日本語, 일시정지·재개, B/C 기존 모드를 확인합니다.

**배포 이전까지 테스트 환경에서 검증한 항목:** JS 문법, D의 한 번/2단계 TTS 호출, 0초 지연의 두 단계 유지, 좌우 사이드 기본값, V1.4 데이터 이전, 언어 매핑, 일시정지·재개. 실제 갤럭시의 음성 출력·서비스 워커 캐시 갱신은 기기에서 추가 확인이 필요합니다.

추가 배포 단계는 `DEPLOY_GUIDE_KO.md`에 설명되어 있습니다.
