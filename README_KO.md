# Shuttle Cue V1.6 — 3개 언어 UI 지원

밝은 파스텔 하늘색 디자인을 유지한 배드민턴 개인 훈련용 PWA입니다. V1.5의 A/B/C/D 훈련 동작과 음성 타이밍·그립 번호·조합 기본값은 변경하지 않았습니다.

## V1.6에서 바뀐 점

- **화면 표시 언어:** 한국어 / 日本語 / English, 앱 상단 🌐 선택 메뉴에서 전환
- 처음 방문한 경우 브라우저가 한국어면 한국어, 일본어면 일본어, 그 외에는 영어로 시작합니다.
- **V1.5 이전 설정에서 업데이트하면 한국어 화면을 유지**하고, 원할 때 언어를 바꿀 수 있습니다.
- **화면 언어와 음성 언어는 독립적:** 일본어 화면 + 영어 음성, 영어 화면 + 한국어 음성 등 자유 조합
- 언어 선택값은 기기에 자동 저장됩니다. 훈련 중에는 실수로 바뀌지 않도록 화면 언어 선택이 비활성화됩니다.
- 훈련 중 표시되는 방향·스트로크, D 조합 선택, 모든 설정 설명, 경고·완료 메시지와 접근성 설명도 화면 언어에 따라 바뀝니다.
- 모든 파일은 정적 파일이며 Python 서버, 로그인, 데이터베이스, 사용자 추적 기능이 없습니다.

## 유지되는 기능

| 모드 | 훈련 | 음성/신호 |
|---|---|---|
| A. Reaction | 랜덤 스플릿 스텝 | 짧은 비프음 |
| B. Footwork | 8방향 풋워크 | 선택한 음성 언어로 방향 발화; 복귀 시간 + 랜덤 대기 |
| C. Grip | 번호 1~10 그립 전환 | 선택한 음성 언어로 숫자 발화 |
| D. Combo | 방향 + 코너별 스트로크 | 2단계 지시 또는 한 번에 지시 |

- A/B/C/D 랜덤 신호 간격: 0.1~5.0초, 0.1초 단위 조절
- B의 중앙 복귀 시간: 0~8초, 0.1초 단위
- D의 방향→스트로크 간격: 0~2초, 0.1초 단위 (2단계 지시)
- D의 스트로크 후 중앙 복귀 시간: 0~8초, 0.1초 단위
- D의 좌우 사이드에는 드라이브 + 스매시가 기본 선택; 전체 25개 기본 조합
- 음성 언어: English (US) / 한국어 / 日本語; 음성 속도: 0.8~1.6배
- 훈련 시간 선택, 설정 저장, 시작 카운트다운, 일시정지·재개, 진동 없는 부드러운 애니메이션

## 언어 설정 방법

1. 앱 오른쪽 위 🌐 **화면 언어** 선택에서 한국어 / 日本語 / English를 선택합니다.
2. B/C/D 모드의 하단 **음성 언어**를 원하는 언어로 별도로 선택합니다.
3. 예: 화면은 `日本語`, 음성은 `English (US)`로 설정해도 정상입니다.
4. 훈련 중에는 표시 언어가 잠기므로 종료 후 바꿉니다.

## 새로 배포하거나 V1.5에서 업데이트

**중요: 이번부터 `i18n.js`가 새로 추가되었습니다.** `index.html`, `app.js`, `styles.css`, `i18n.js`, `manifest.webmanifest`, `service-worker.js`, `icons/` 폴더를 GitHub 저장소의 루트에 함께 업로드하세요. `README_*.md` 파일은 앱 구동에 필수는 아닙니다.

기존 공개 주소: `https://kylemkim.github.io/shuttle-cue/`

1. ZIP을 압축 해제합니다.
2. GitHub 저장소의 `Code` 탭에서 동일 이름의 앱 파일을 새 버전으로 교체하고 **새 파일 `i18n.js`도 업로드**합니다.
3. `Commit changes` 후 `Actions`에서 Pages 배포 성공을 확인합니다.
4. 사이트를 새로고침하여 하단 `v1.6 · PWA` 및 상단 🌐 언어 메뉴를 확인합니다.
5. 예전 화면이 계속 남으면 사이트/설치 앱을 완전히 닫고 다시 연 뒤 새로고침합니다. PWA 캐시 반영에 시간이 걸릴 수 있습니다.

설치 안내는 `DEPLOY_GUIDE_KO.md`에 더 자세히 설명했습니다.

## 사용 시 주의 사항

- 음성은 Android/Chrome의 Web Speech API 및 기기에 설치된 TTS 엔진을 사용합니다. 영어·한국어·일본어 음질과 발화 소요시간은 기기에 따라 달라집니다.
- B/C 모드에서 신호 간격이 발음 시간보다 짧으면 앞 음성이 중간에 끊어질 수 있습니다.
- D 모드는 방향 음성과 스트로크 음성이 겹치지 않게 순서대로 출력합니다. 2단계 지시의 **0초 간격은 동시발화가 아니며**, 한 번에 지시는 한 문장으로 읽습니다.
- 화면이 꺼지거나 앱을 다른 앱으로 전환하면 훈련이 자동 일시정지됩니다.
- PWA 자체 파일은 오프라인 캐시를 사용하지만 **TTS의 오프라인 동작은 기기 음성 데이터 설치 여부에 따라 달라집니다.**
- GitHub Pages는 정적 파일을 공개합니다. 소스코드가 공개되므로 비밀키나 개인 식별정보를 저장소에 올리지 마세요.
