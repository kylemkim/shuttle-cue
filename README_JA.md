# Shuttle Cue V1.6 — バドミントン自主練アプリ

パステル調の明るい水色デザインを採用した、インストール可能なバドミントン自主練用PWAです。ログイン・課金・専用サーバーは不要です。

## 表示言語と音声言語

画面上部の 🌐 メニューから、**日本語・English・한국어** の表示を切り替えられます。初めて開く場合、対応するブラウザ言語を自動選択し、それ以外は英語になります。選択結果は端末に保存されます。

**表示言語と読み上げ言語は別々に設定できます。** 例：日本語の画面で英語の指示音声を聞く場合、上部を「日本語」にして、B/C/Dモードの「読み上げ言語」を「English (US)」にします。練習中は表示言語の変更がロックされます。

## 練習モード

- **A. Reaction：** ランダムなビープ音に合わせてスプリットステップを練習。
- **B. Footwork：** 8方向の音声指示に合わせて移動。中央に戻る時間とランダム待機を別々に設定。
- **C. Grip：** 1～10の数字を聞いて、フォア／バックのグリップを切り替える練習。
- **D. Combo：** 方向とショットの組み合わせ。2段階指示、または一度に指示する方式を選択。コースごとのショットを自由にチェックできます。

間隔は **0.1秒単位**で調整できます。Dモードの初期設定は25組で、左右サイドのドライブとスマッシュも含まれます。V1.5の基本動作は変更していません。

## スマホへのインストール

GitHub PagesなどのHTTPSサイトで公開した後、Android Chromeで開き、メニューから「アプリをインストール」または「ホーム画面に追加」を選択してください。アプリ用ファイルはオフラインキャッシュに保存されます。ただし、TTS音声データによってはネット接続が必要な場合があります。

## 開発者向けアップデート

V1.5のGitHub Pagesを更新する場合は、`index.html`・`styles.css`・`app.js`・`manifest.webmanifest`・`service-worker.js`・`icons/` に加えて、新規ファイル **`i18n.js`** もリポジトリのルートへアップロードしてください。コミット後、Pagesのデプロイ成功を確認します。新しいリポジトリは不要です。

## 注意

- 音声合成はChromeと端末のTTS環境に依存します。
- 合図間隔が短すぎると、前の音声が途中で切れることがあります。
- Dモードの「2段階指示」の間隔0秒は、2つの音声を順に再生します。「一度に指示」では1つの文章として読み上げます。
- 画面を消したり、別アプリに切り替えたりすると練習は自動で一時停止します。
- ログインや利用状況の追跡、個人データのサーバー保存機能はありません。
