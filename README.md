# Shuttle Cue — Solo Badminton Training PWA 🏸

**English | [日本語](README_JA.md) | [한국어](README_KO.md)**

An installable sky-blue badminton training app featuring split-step reaction cues, eight-direction footwork, 1–10 grip practice and customizable direction-to-stroke combinations.

V1.6 adds three display languages (English, Japanese and Korean). **The interface language is independent of spoken cue language** — for example, you can train with English audio while using the Japanese interface.

For features and installation details see **[English guide](README_EN.md)**. For updating the owner's existing GitHub Pages deployment see **[한국어 GitHub 가이드](DEPLOY_GUIDE_KO.md)**.

No registration, tracking, or server database. The PWA uses Web Speech API voices supplied by your browser/device, and voice availability may vary offline.
